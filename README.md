# 星徒地牢

MYSKME 世界观下的单文件像素战术地牢最终课堂版。含单人九层远征与一至六人课堂模式，
支持全员判分后立即计算行动、团体与个人积分、差异化职业技能、星币商店、策略二周目、
谜卷研究、路线抉择、遗物构筑、本地战绩海报、本机多维榜与云端榜。

- 在线地址：https://myskme.github.io/myskme-star-dungeon/
- 源提交：`317c53b3a69965dd8656d99c0099c62a2d5bb015`（`myskme/myskme-expedition` 的 `像素地牢/星徒地牢.html`）
- 权威设计与维护说明：[像素地牢／说明.md](https://github.com/myskme/myskme-expedition/blob/main/%E5%83%8F%E7%B4%A0%E5%9C%B0%E7%89%A2/%E8%AF%B4%E6%98%8E.md)
- 云端榜只公开个人昵称或队名，不公开课堂成员姓名

## 设计精髓

课堂按一轮 5 至 6 题组织：全班共同作答，全员在同一页选择行动倍率，最后只点一次“立即计算”；
系统生成个人与团队积分后，全队再选择计谋并完成一轮行动。答题提供资源，路线、站位、职业配合、
机关和击杀顺序决定能否通关。

三至四人是默认推荐编制。二周目通过铁网阵、笑爆阵和守门阵增加策略难度，不靠单纯堆血；
摸鱼怪、御前蕉皮和地图异闻负责制造轻松时刻，但每个笑点同时具有玩法价值。

探索层通过六组谜卷案件、三类路线与八件遗物提供可研究的长期变化。线索会保留，错误答案会
留下提示；路线改变下一层规则，三格遗物装配则形成可讨论、可复盘的队伍构筑。
