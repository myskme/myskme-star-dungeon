# 星徒地牢

MYSKME 世界观下的单文件像素战术地牢最终课堂版。含单人九层远征与一至六人课堂模式，
支持全员判分后立即计算行动、团体与个人积分、差异化职业技能、星币商店、策略二周目、
本地战绩海报、本机多维榜与云端榜。

- 在线地址：https://myskme.github.io/myskme-star-dungeon/
- 源提交：`24bb357b4a606be4a15638f5f7fe79fa88e071a3`（`myskme/myskme-expedition` 的 `像素地牢/星徒地牢.html`）
- 云端榜只公开个人昵称或队名，不公开课堂成员姓名

## 本地打开

下载 `index.html`，用浏览器直接打开即可。无需联网、无需服务器、无需安装。

## 说明

整个作品就是一个 HTML 文件，不依赖外部资源或脚本库。像素图形与音效均由代码生成；
离线时游戏、存档和本机榜完全可用，只有共享排行榜需要联网。
