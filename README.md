# 星徒地牢

MYSKME 世界观下的单文件像素战术地牢最终课堂版。含单人九层远征与一至六人课堂模式，
支持全员判分后立即计算行动、团体与个人积分、差异化职业技能、星币商店、策略二周目、
谜卷研究、路线抉择、遗物构筑、本地战绩海报、本机多维榜与可靠云端榜，并拥有覆盖菜单、
课堂、地牢、头目、研究与结算的自适应像素音频。

## 设计精髓

课堂按一轮 5 至 6 题组织：全班共同作答，全员在同一页选择行动倍率，最后只点一次“立即计算”；
系统生成个人与团队积分后，全队再选择计谋并完成一轮行动。答题提供资源，路线、站位、职业配合、
机关和击杀顺序决定能否通关。

三至四人是默认推荐编制。二周目通过铁网阵、笑爆阵和守门阵增加策略难度，不靠单纯堆血；
摸鱼怪、御前蕉皮和地图异闻负责制造轻松时刻，但每个笑点同时具有玩法价值。

探索层通过六组谜卷案件、三类路线与八件遗物提供可研究的长期变化。线索会保留，错误答案会
留下提示；路线改变下一层规则，三格遗物装配则形成可讨论、可复盘的队伍构筑。

## 手机体验

- 方向键支持快速连续点按，不会再触发浏览器双击放大。
- 主菜单“装到主屏”提供 iPhone、iPad、Android 和电脑安装引导。
- 正式网站提供黑金赤狐像素图标、独立窗口、主题色和离线启动增强。
- 页面其他区域仍保留正常缩放能力，不牺牲无障碍体验。

## 本地打开

下载 `index.html`，用浏览器直接打开即可。无需联网、无需服务器、无需安装。

## 说明

游戏核心仍是一个可以独立运行的 HTML 文件，不依赖外部脚本库。像素图形、二十余类操作音效和九套
分场景 BGM 均由代码生成；正式网站额外提供 Manifest、图标和 Service Worker 作为渐进增强。
离线时游戏、存档和本机榜完全可用，只有共享排行榜需要联网；客户端不再直连
`workers.dev`。
